# CV Interactivo

Sitio web interactivo de currículum con landing page del iPhone 18 Pro.

## Características

- CV personal con diseño oscuro y efectos neon.
- Landing page del iPhone 18 Pro con galería de imágenes.
- Animaciones reveal y transiciones suaves.
- Totalmente responsive (móvil y desktop).
- Estilos CSS personalizados con variables y glassmorphism.

## Estructura

```
.
├── index.html          # CV principal
├── proyecto.html       # Landing iPhone 18 Pro
├── assets/
│   ├── iphone-18-pro-azul-glacial.jpg
│   ├── iphone-18-pro-burdeos.jpg
│   ├── iphone-18-pro-negro.jpg
│   └── iphone-18-pro-plata.jpg
└── style/              # (opcional, estilos adicionales)
```

## Despliegue

Puedes abrir los archivos directamente o usar un servidor local:

```bash
python -m http.server 8000
# o
npx serve
```

Luego visita http://localhost:8000 o la URL que proporciones.
